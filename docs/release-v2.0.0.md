## 电气知识卡片 2.0

此次更新把展示方式改为手机桌面大卡片，支持缩放、摘要分页、上一条/下一条、收藏和点击阅读全文。

- 15 条扩写知识，涵盖配电、MCC、冷水机组、UPS、数据中心规范。
- 本地 SQLite 知识库，支持手机新增、编辑、删除、搜索、收藏。
- CSV 导入预览、同编号更新、整批校验，支持导出备份。附带可编辑的 knowledge-template.csv。
- 1—365 小时/天自动轮换，可暂停、选择分类。系统省电可能延迟轮换。
- 不需要通知权限，不运行常驻前台服务，也不需要账户或联网阅读。

### 安装与添加卡片

需要 Android 13 或以上。下载安装下方 APK，打开“电气知识卡片”，点“添加桌面大卡片”，在系统提示中确认。
如果桌面不支持该按钮，请长按桌面空白处 → 小组件（或添加工具）→ 电气知识大卡片。长按已有卡片可调整大小；点标题阅读正文，卡片底部可以翻页、换条和收藏。

### 自己更新知识库

在“知识库”页面点“新增”，或导入附带的 CSV 模板。推荐先导出全部知识，用 Excel 编辑后另存为 CSV UTF-8，再导入；保留 id 会更新同一条记录，留空 id 会新建。
导入会显示新增和更新数量，确认后写入。支持中文表头，最多 2000 条/2 MB。知识保存在本机，卸载或换机前请导出。

### 测试版签名说明

这是 Debug 测试包。GitHub Runner 生成的调试签名可能与旧测试版不同，若提示“签名冲突”或“应用未安装”，请先备份需要的数据，再卸载旧测试版并安装本版。正式发行和长期覆盖升级需要固定的发布签名。

桌面样式与可选网格大小由手机桌面决定；小米/HyperOS 真机显示效果仍需在设备上确认。
